# 语言机制检查清单（起步版）

> 这是复核层一的判断依据。**只报能被 diff 证伪的缺陷**，不报风格偏好，不重复编译器、lint、静态分析已能可靠判定的东西。
> 起步版按常见缺陷类写，实际使用中按项目真实缺陷补充。语言清单会随版本演进过时，**只保留在用的语言**。
> 部分条目参考 [alibaba/open-code-review](https://github.com/alibaba/open-code-review) 的 `swift.md` 与 `objc.md`（Apache-2.0），按其许可保留署名。

## 通用纪律（先于任何语言）

- **报之前先取证**：涉及跨文件行为（调用方、生命周期、同步方式、输入来源）先用 grep / 读文件确认，不靠名字和类型推断。
- **只报可达路径**：改动里不可达的分支、编译器已保证的约束，不报。
- **分级固定四档**：`critical`（崩溃、数据损坏、安全问题）/ `high`（明确的行为错误）/ `medium`（边界条件、资源生命周期）/ `low`（可维护性）。**不得自造级别。**
- **不得因「我觉得没问题」删掉这三类**：内存安全、并发、行为兼容性变更。它们删错的代价最高，而自信最不可信。

## Swift

### 可选值与运行时失败
- 对运行时来源的值（用户输入、网络响应、持久化、解码、外部状态）force unwrap / force cast / `try!`，且失败可达。
- 隐式解包可选值在受控生命周期之外使用（初始化前、失效后访问）。
- 可选处理把必要失败转成静默错误行为或无效状态。

### 内存与 ARC
- 逃逸闭包强捕获其持有者，形成循环引用。
- `[unowned]` 在生命周期无保证的逃逸闭包中使用。
- delegate / observer / timer / task 形成所有权环，或在持有者销毁后继续工作。
- Combine 订阅在持有 cancellable 的对象内强捕获 `self`，导致预期释放不发生。

### 错误处理
- 抛错操作或 `Result` 失败被忽略、替换成成功值，而失败会改变数据正确性。
- `try?` 抹掉了调用方需要的失败区分。
- 空 catch 吞掉了影响完整性、安全或用户可见行为的失败。
- 对可恢复的运行时失败使用 `fatalError` / `preconditionFailure`。

### 并发与隔离
- 可变状态跨 actor 边界访问，无隔离或同步。
- 非 `Sendable` 值跨隔离边界传递。
- 未经证明的 `@unchecked Sendable` 或 `nonisolated(unsafe)`。
- 从回调、delegate、闭包访问 actor 隔离状态而未保持隔离。
- fire-and-forget task 超出持有者生命周期、无法取消、或结束后继续产生副作用。
- 异步工作忽略取消，继续做昂贵计算。
- continuation 可能多次 resume、从不 resume、或在生命周期失效后 resume。
- 在 `await` 边界两侧持锁或同步等待。

### SwiftUI 状态与生命周期
- 视图持有的引用状态因所有权错误在每次渲染时重建。
- 动态集合使用不稳定身份，导致行复用或状态错配。
- 在 `body` 或计算属性里执行副作用。
- `.task(id:)` 缺失，导致被替换的输入让旧结果覆盖新状态。
- 并发更新可能时，在 main actor 隔离之外修改 UI 状态。
- 新增或修改了面向用户的字符串却没有本地化覆盖。

### 持久化与数据完整性（SwiftData / Core Data）
- 写入失败后留下部分更新或不一致状态。
- schema 或关系变更无兼容迁移处理。
- 关系配置变更导致孤儿对象、无效引用或错误删除行为。
- 谓词或排序描述符匹配到错误数据，或造成不必要的昂贵查询。
- 把缓存值当权威，而它可能过期并影响正确性。

## Objective-C

### 所有权与 ARC
- 强引用环：block 强捕获 `self` 且 `self` 持有该 block。
- `weak` 对象在使用前未提升为强引用，出现中间态 nil。
- `assign` 修饰对象类型；`copy` 缺失于 NSString/NSArray 等可变子类属性。
- `dealloc` 中未取消通知、timer、KVO 观察。

### Block、回调与定时器
- block 内修改外部变量未加 `__block`，或误用导致预期外的捕获语义。
- timer 强持有 target 且未 invalidate，形成环并持续触发。
- 回调在非预期队列上执行，调用方假设了主线程。

### 初始化与构造
- `init` 中调用可被重写的实例方法。
- 返回 nil 的 `init` 未清理已分配资源。
- 分类里重写原类方法（行为不确定），或同名分类方法重复定义。

### 集合、字符串与范围
- `NSMutableArray` / `NSMutableDictionary` 遍历中修改。
- 越界索引、`NSRange` 计算溢出（`NSMaxRange`、负长度）。
- 字符串下标按 UTF-16 长度当字符数使用。

### 并发与主线程
- UI 更新不在主线程。
- 同一串行队列内 `dispatch_sync` 造成死锁。
- 属性读写跨线程无同步，或 `atomic` 被误当成线程安全（复合操作仍非原子）。

### KVC / KVO / 通知
- KVO 观察未移除，或移除次数与添加不匹配。
- KVC 用字符串键访问，键名拼写错误只在运行时暴露。
- 通知未在主线程处理却更新 UI。
